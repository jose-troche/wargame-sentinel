# WARFARE SENTINEL — conventions for coding agents

Read `docs/specs.md` (what) and `docs/implementation.md` (how) before changing behaviour.

## Layout
- `packages/protocol` — every frame type, view type, the order schema (Zod) and msgpack codecs.
- `packages/catalog` — the 42 notional asset classes (bands only), band→number tables, scenario validator, role authority.
- `packages/engine` — deterministic World Engine (`Engine.step`, `Engine.stepSlice`), AAR metrics.
- `packages/agents-rules` — rule-based role policies and the cadence scheduler.
- `scenarios/` — starter scenarios, generated by `tools/gen-scenarios.mjs` (edit the generator, then run it).
- `apps/edge` — Worker, `SessionDO`, `FactionAgent` (Agents SDK), `UsageDO`.
- `apps/console` — React SPA; the engine runs in `src/engine/worker.ts`. `src/game` is the command-post logic
  (briefing prioritizer, decision cards, Ask interpreter, plays → orders); `src/command` is its UI; `src/consoles` are the expert consoles.

## Invariants
- The engine never imports platform APIs, and never uses `Math.random`, `Date`, or `Math.sin/cos/atan2/exp/log/pow`
  (use `dmath` and the seeded `Rng`). Iterate arrays and insertion-ordered maps only. Determinism is tested.
- `apps/edge/src/faction.ts` and `prompts.ts` never import `@sentinel/engine` (ground truth). A static test enforces it.
- Faction views and COPs never carry truth ids, enemy entities or enemy messages (`views.ts` is the boundary).
- Every frame type lives in `packages/protocol`.
- Performance values are bands, never precise numbers; factions and place names are fictional. The validator rejects violations.
- Orders from LLMs, rules and humans all go through `applyOrderBatch` and the C2 network; nothing teleports a task to a unit.
  Command-post plays and decisions are just order batches from the commander's seat (`src/game/actions.ts`).
- The command-post layer (`src/game`) reads only the player's faction view, never ground truth or WHITE data.

## Commands
- `pnpm -r typecheck && pnpm -r test` — unit tests (determinism, fog of war, contracts, placements).
- `pnpm --filter @sentinel/console e2e` — Playwright headless browser tests.
- `pnpm bench:slices` — Profile A slice timings.
- `pnpm deploy` — build the console and `wrangler deploy` the Worker.
